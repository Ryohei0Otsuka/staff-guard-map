# Staff Guard Map

欠員時の体制維持と、バッファー人員の考え方を整理するための検討用プロトタイプです。

https://ryohei0otsuka.github.io/staff-guard-map/

## 見るポイント

* 日勤・夜勤はそれぞれ最低2人
* 2人未満の場合はアラート
* 日勤・夜勤は1.0、バッファーは0.5、休みは0として表示
* バッファーは即時補填保証ではなく、欠員時の補填候補枠
* 人件費は概算表示

## 注意

具体的な勤務時刻は、実運用・勤怠・契約に関わるため、このプロトタイプでは固定しません。

実際の勤怠、契約、単価、待機扱い、顧客報告は、上長・営業・管理側との確認が必要です。
